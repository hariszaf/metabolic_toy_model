# Introduction in metabolic modeling

## Topics to be discussed

Hell friend. 

In this introduction, we will cover some first topics regarding **GEnome-scale Metabolic reconstruction (GEM)**. 
We will also go through a few methods of **constraint-based analysis (CBA)** that are typically used with GEMs.
Last, we will make ourselves familiar with the `cobra` Python library, that is commonly used for parsing and analysing such models. 


## How to work with this repo 

You can either clone this repo by: 


    git clone https://github.com/hariszaf/metabolic_toy_model.git
    cd metabolic_toy_model

and jump to the `duth` branch:

    git checkout duth


**or**, you can fire a [codespace](https://github.com/features/codespaces). 


&#x1F534; In both cases, **you need to first** follow the instructions you will find in the [`pre_env.ipynb`](./prep_env.ipynb) notebook!

Once you have set your environment, you are ready to go for the actual metabolic modeling tasks! 

For any issue or quesion of yours, feel free to contact [Haris](mailto:haris.zafeiropoulos@atomicmail.io).
